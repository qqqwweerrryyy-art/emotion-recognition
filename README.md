# Мультимодальное распознавание эмоций (лицо + голос + жесты)

Учебный проект по предмету «Распознавание образов». Цель: система, которая по **записанному видео**
определяет эмоцию человека по трём источникам: выражению лица, голосу и жестам рук.
Режим реального времени не требуется, достаточно обработки видеофайлов.

Срок проекта: один месяц с 10.11.2026.

Требование курса: можно использовать готовые (предобученные) модели, но дообучать их нужно самостоятельно.
В проекте так и сделано: ResNet18 (ImageNet) и wav2vec2-base дообучаются на RAVDESS и на CREMA-D
(две независимые пары моделей, при распознавании видео используются обе, см. раздел 7).

> **Важно прочитать до начала работы:** обученные модели, данные и результаты **не хранятся в Git**
> (см. `.gitignore`). Чтобы продолжить работу, нужно заново скачать данные и обучить модели
> (раздел «Как воспроизвести»). Для показа на другом компьютере достаточно скопировать веса (раздел 14).

## 2. Результаты

Данные: RAVDESS, 24 актёра, 7 классов. Деление **по актёрам**, seed 42:

- обучение: актёры 2, 13, 22, 7, 10, 3, 23, 5, 20, 8, 9, 1, 4, 21 (14 человек);
- проверка (выбор лучшей эпохи и веса слияния): 11, 18, 12, 15, 17;
- тест: 16, 6, 19, 24, 14 (5 человек, 300 видео).

| Модель | Единица оценки | Accuracy | Macro-F1 |
|---|---|---|---|
| Лицо, ResNet18, замороженная основа (`frozen`) | кадр (n=2999) | 0.399 | 0.378 |
| Лицо, ResNet18, дообучен `layer4` (`partial`) | кадр (n=2999) | 0.538 | 0.472 |
| Лицо, `partial`, среднее по кадрам видео | видео (n=300) | 0.557 | 0.476 |
| Голос, MFCC + SVM (базовая) | видео (n=300) | 0.553 | 0.540 |
| Голос, wav2vec2, `frozen` | видео (n=300) | 0.553 | 0.516 |
| Голос, wav2vec2, `partial` (4 верхних блока) | видео (n=300) | **0.737** | **0.720** |
| Лицо + голос, веса 50/50 | видео (n=300) | **0.817** | **0.801** |
| Лицо + голос, вес лица 0.2 (выбран по проверке) | видео (n=300) | 0.737 | 0.720 |

Случайный уровень около 14%, «всегда нейтральная» около 20%.

F1 по классам на тесте:

| Класс | Лицо (`partial`, кадры) | Голос (wav2vec2 `partial`) |
|---|---|---|
| neutral | 0.70 | 0.78 |
| happy | 0.73 | 0.58 |
| sad | 0.44 | 0.52 |
| angry | 0.48 | 0.75 |
| fearful | 0.07 (recall 0.04) | 0.77 |
| disgust | 0.65 | 0.79 |
| surprised | 0.24 | 0.84 |

### 2.1. CREMA-D (6 классов, без `surprised`)

Данные: CREMA-D, 91 актёр, 7442 клипа, деление по актёрам, seed 42: 68 обучение / 8 проверка / 15 тест.
Классы: neutral, happy, sad, angry, fearful, disgust. Обучены только режимы `frozen`
(обучается лишь последний слой).

| Модель | Accuracy | Macro-F1 |
|---|---|---|
| Лицо, ResNet18, `frozen` | 0.362 | 0.351 |
| Голос, wav2vec2, `frozen` | 0.527 | 0.523 |

Эти числа **нельзя сравнивать** с таблицей RAVDESS выше: другой набор данных, 6 классов вместо 7 (случайный уровень
около 17%, а не 14%), другие тестовые актёры, и там `partial`, а здесь `frozen`. Корректное сравнение дают
только режимы `frozen` с `frozen` и `partial` с `partial`, и `partial` на CREMA-D ещё не запускался.
Объединённая оценка «старые + новые модели» на общем тесте тоже не посчитана.

Наблюдение на нескольких сторонних роликах (не измерение): лицевая модель CREMA-D часто выдаёт `disgust`.

### Как читать эти цифры

- Выводы, которым можно доверять: дообучение заметно лучше замороженной основы (лицо +14 п.п.,
  голос +18 п.п. accuracy); объединение лица и голоса лучше любой модальности по отдельности.
- Тест маленький (300 видео), погрешность порядка ±5 п.п. Разница в 1-3 п.п. ничего не значит.
- Один запуск, один seed, одно деление по актёрам. Для отчёта желательно повторить с `--seed 1` и `--seed 2`
  и привести среднее.
- Вариант 50/50 выбран заранее как простой, но сравнение вариантов слияния смотрели на тесте,
  так что 0.817 нельзя называть результатом «лучшего подбора». В отчёте это нужно оговорить.
- Вес лица 0.2 «выбрался» по проверке потому, что на проверочных актёрах качество почти не меняется
  при весе от 0.2 до 0.5 (macro-F1 0.760-0.764), а код брал первое из равных значений.
  Результат совпал с голосом отдельно.
- Кадры одного видео почти одинаковы, поэтому 10 кадров на видео это не 10 независимых примеров.
- RAVDESS это актёрская игра двух одинаковых фраз на североамериканском английском, снятая в студии.
  На обычных видео точность будет заметно ниже.

## 5. Данные

**RAVDESS** (Ryerson Audio-Visual Database of Emotional Speech and Song), 24 актёра. Скачивается с Zenodo
(поиск «RAVDESS Zenodo», запись 1188976). Нужны архивы `Video_Speech_Actor_01.zip` ... `24.zip`.
Распаковать в `data/ravdess/` так, чтобы получились папки `Actor_01` ... `Actor_24` с файлами `.mp4`.
Условия использования смотрите на странице набора.

Имя файла кодирует разметку: `01-01-06-01-02-01-12.mp4`

| Позиция | Значение |
|---|---|
| 1-е число | тип: 01 видео со звуком (используем только такие), 02 только видео, 03 только звук |
| 3-е число | эмоция: 01 neutral, 02 calm, 03 happy, 04 sad, 05 angry, 06 fearful, 07 disgust, 08 surprised |
| последнее число | номер актёра (по нему делится выборка) |

В проекте 7 классов: `calm` объединён с `neutral`.
Порядок классов во всём коде одинаков и менять его нельзя:

```python
CLASSES = ["neutral", "happy", "sad", "angry", "fearful", "disgust", "surprised"]
CODE2CLS = {1: 0, 2: 0, 3: 1, 4: 2, 5: 3, 6: 4, 7: 5, 8: 6}
```

Проверка числа файлов: должно быть 1440 (60 на актёра).

```powershell
(Get-ChildItem data\ravdess -Recurse -Filter "01-*.mp4").Count
```

**CREMA-D** (Crowd-sourced Emotional Multimodal Actors Dataset), 91 актёр, 7442 клипа, предложения на английском.
Репозиторий на GitHub (`CheyneyComputerScience/CREMA-D`) хранит файлы через git-lfs, поэтому нужен установленный

Если файлы получились крошечными (несколько сотен байт), это заглушки, а не данные.
Имя файла: `1001_DFA_ANG_XX`: актёр, фраза, эмоция (NEU, HAP, SAD, ANG, FEA, DIS), интенсивность.
Эмоции «удивление» в наборе нет. Условия использования смотрите на странице набора.

## 6. Как воспроизвести результаты

Скрипты запускать по порядку, по одному (видеокарта на 3 ГБ не потянет два обучения одновременно).

```powershell
# 1. Лица из видео (~7 минут на 1440 видео). Итог: 14398 кропов, 2 кадра без лица.
python src\extract_faces.py
#    для быстрой отладки: python src\extract_faces.py --limit 5

# 2. Лицо
python src\train_face.py --mode frozen  --epochs 15 --lr_head 0.003
python src\train_face.py --mode partial --epochs 8
python src\face_probs.py --mode partial      # вероятности по видео для слияния

# 3. Голос
python src\audio_baseline.py                 # MFCC + SVM, заодно создаёт wav в data\audio
python src\train_audio.py --mode frozen  --epochs 15
python src\train_audio.py --mode partial --epochs 10

# 4. Слияние
python src\fuse_face_audio.py
```

Результаты каждого скрипта пишутся в `outputs/` (матрицы ошибок `*_cm.png`, метрики `*_metrics.json`,
веса `*.pth`, вероятности `*_probs.csv`).

Проверка согласованности: во всех запусках строка `Актёры: train=... val=... test=...` должна быть одинаковой.
Побитовая воспроизводимость не гарантируется (GPU, смешанная точность), небольшие отличия в цифрах допустимы.

## 7. Как пользоваться

Нужны обученные веса `outputs/face_partial.pth` и `outputs/audio_w2v_partial.pth`.

```powershell
# Результат по одному видео (лицо, голос, итог в процентах)
python src\predict_video.py "путь\к\видео.mp4"

# Результат по видео сразу ВСЕМИ моделями (RAVDESS и CREMA-D вместе)
python src\predict_ensemble.py "путь\к\видео.mp4"

# Только модели CREMA-D
python src\predict_video_cremad.py "путь\к\видео.mp4"

# Только голос (видео или аудио)
python src\predict_audio.py "путь\к\файлу.mp4"

# Видео с рамкой вокруг лица и подписью эмоции -> outputs\annotated\<имя>_annotated.mp4
python src\annotate_video.py "путь\к\видео.mp4"

# Точность на своей размеченной выборке: test_videos\<класс>\*.mp4, классы как в CLASSES
python src\eval_folder.py
```

Полезные параметры `annotate_video.py`: `--no_voice` (только лицо), `--w_face 0.3` (вес лица в итоге),
`--alpha 0.2` (сильнее сглаживание подписи), `--step 5` (быстрее).

`predict_ensemble.py` объединяет модели так: для каждого класса берётся среднее по тем моделям, которые этот класс
знают (`surprised` знают только модели RAVDESS), затем вероятности нормируются; лицо и голос смешиваются
с весом `--w_face` (по умолчанию 0.5, не подбирался). Порядок классов в 6-классовых моделях принят как `CLASSES` без
`surprised`; если обучающие скрипты CREMA-D используют другой порядок, нужно поправить `CLASSES6` в скрипте.
Какие веса брать, задаётся параметрами `--face_weights` и `--audio_weights`.

Подробная инструкция для запуска на другом компьютере: раздел 14.

Если в видео нет звука или он тише порога, голос не используется и итог строится по лицу.
Порог RMS 0.003 выбран приблизительно и не калибровался.

## 8. Как устроен код

Поток данных:

```
RAVDESS mp4 ──extract_faces──► data/faces/actor_XX/*.jpg + labels.csv
                                   │
                                   └─train_face──► outputs/face_{mode}.pth ──face_probs──► outputs/face_{mode}_probs.csv
RAVDESS mp4 ──ffmpeg──► data/audio/*.wav
                                   │
                                   └─train_audio──► outputs/audio_w2v_{mode}.pth, outputs/audio_{mode}_probs.csv
                                                                  │                        │
                                                                  └────────fuse_face_audio─┘
```

### Лицо (`extract_faces.py`, `train_face.py`, `face_probs.py`)

- Из каждого видео берутся 10 кадров из диапазона 20-80% длительности. Лицо ищется каскадом Хаара, берётся самое
  крупное, вырезается квадрат с запасом 30%, масштабируется до 224×224.
- Модель: ResNet18 (ImageNet), последний слой заменён на `Dropout(0.3) + Linear(512, 7)`.
  - `frozen`: учится только последний слой.
  - `partial`: дополнительно размораживается `layer4` (lr 1e-4, у головы `--lr_head`, по умолчанию 1e-3).
- BatchNorm в замороженных частях остаётся в режиме eval.
- AdamW (weight decay 1e-4), косинусное расписание, смешанная точность, батч 32.
- Аугментация: случайная обрезка (0.8-1.0), отражение, поворот ±10°, изменение яркости/контраста/насыщенности.
- Лучшая эпоха выбирается по macro-F1 на проверочных актёрах; тест используется один раз в конце.
- Деление по актёрам: функция `split_actors(actors, seed)` в `train_face.py` (сортировка, перемешивание через
  `random.Random(seed)`, 20% на тест, 20% на проверку). Копия этой функции есть в `train_audio.py`.
  Если меняете деление, меняйте в обоих файлах и **переобучайте обе модели**, иначе слияние станет нечестным.

### Голос (`audio_baseline.py`, `train_audio.py`)

- Звук вытаскивается ffmpeg (моно, 16 кГц), тишина по краям обрезается (`top_db=30`), громкость нормализуется.
- База: признаки MFCC(40) + дельты + RMS + ZCR (среднее и стандартное отклонение по времени), SVM с RBF-ядром,
  перебор `C` из {0.1, 1, 10, 100}, `class_weight="balanced"`.
- Основная модель: `facebook/wav2vec2-base`, усреднение выходов по времени, затем `Dropout(0.3) + Linear(768, 7)`.
  - Фрагменты по 4 секунды (при обучении случайные, при проверке по центру, короткие дополняются повтором).
  - `frozen`: учится только голова. `partial`: размораживаются 4 верхних блока трансформера
    (параметр `--unfreeze`, lr 5e-5), голова lr 1e-3.
  - Батч 8, смешанная точность. Все звуки загружаются в оперативную память.
- Wav2vec2 в `partial` сильно переобучается (потери на обучении падают до 0.006), поэтому лучшая эпоха выбирается
  по проверке (в запуске это 7-я).

### Слияние (`fuse_face_audio.py`)

Late fusion: `p = w·p_лица + (1−w)·p_голоса` по видео. Вероятности лица усреднены по кадрам видео
(`face_probs.py`). Вес подбирается по macro-F1 на проверочных актёрах на сетке 0.0-1.0 с шагом 0.1.

### Инференс (`predict_video.py`, `annotate_video.py`)

- `predict_video.py`: 10 кадров между 10% и 90% длительности, звук делится на фрагменты по 4 секунды (до 8 штук).
- `annotate_video.py`: лицо ищется каждые 2 кадра, эмоция определяется каждые 3 кадра, вероятности лица
  сглаживаются экспоненциально; голос считается окнами по 4 с с шагом 2 с. В конце печатается, в каком проценте
  кадров найдено лицо, итог по кадрам с лицом и отдельно статистика голоса.

## 9. Известные проблемы

1. **Детектор лиц слабый вне RAVDESS.** На сторонних видео (не анфас, мелкое лицо, вертикальный кадр)
   Haar-каскад часто не находит лицо: на одном тестовом ролике лицо найдено в 2 кадрах из 10.
   Это главный источник проблем при демонстрации на своих видео.
2. **Лицевая модель склонна называть «радость»** на видео не из RAVDESS (наблюдение по нескольким роликам,
   не измерено). Возможные причины: сдвиг данных (свет, ракурс), форма рта при разговоре, мало разных людей
   в обучении (14), ошибки детектора.
3. **Голосовая модель обучена только на английской актёрской речи.** На русской речи и на неречевом звуке
   (музыка, шум) результаты ненадёжны. На ролике с очень громким звуком (RMS ≈ 0.48, предположительно музыка)
   модель выдала близкие вероятности для нескольких классов, то есть уверенности нет.
4. **Выбор веса слияния** берёт первое из равных значений на плато (см. раздел 2). Предлагаемое исправление:
   брать середину всех весов, чьё качество на проверке отличается от лучшего не более чем на 0.005. Это нужно
   описывать в отчёте как общее правило, а не подгонку под тест.
5. **Маленькая оценка:** тест из 5 актёров, один seed.
5а. **Две пары моделей с разными наборами классов** (7 и 6). Ансамбль в `predict_ensemble.py` это обходит, но его
   качество не измерялось, и нет доказательства, что он лучше отдельных моделей.
6. Класс `fearful` у лицевой модели почти не распознаётся (recall 0.04), `surprised` тоже слабый.
7. `eval_folder.py` перезагружает модели для каждого видео, поэтому на десятках видео работает медленно.
8. Windows: если обучение лица зависает или падает из-за `num_workers=2` в `DataLoader`, поставьте 0.
9. MediaPipe установлен, но не используется. Его интерфейс в версии 1.2.2 не проверялся, перед использованием
   для рук проверьте актуальную документацию.

## 14. Запуск на чистом ноутбуке (для показа)

Предполагается Windows и ноутбук, на котором нет ничего. Данные (RAVDESS, CREMA-D) и обучение на ноутбуке
**не нужны**: нужны код из GitHub и готовые веса. Видеокарта не обязательна, на процессоре обработка одного
видео занимает от нескольких секунд до минуты.

### 14.1. Подготовка на основном компьютере (один раз)

1. Убедиться, что весь код закоммичен и запушен (`git status` чистый, `git push`).
2. Скопировать на флешку или в облако (в Git их нет):
   - из `outputs\`: `face_partial.pth`, `audio_w2v_partial.pth`, `face_cremad_frozen.pth`, `audio_cremad_w2v_frozen.pth`;
   - 3-4 демонстрационных видео (с лицом и голосом, без звука, одно сложное) и заранее созданные
     `outputs\annotated\*_annotated.mp4` как запасной вариант;
   - матрицы ошибок `outputs\*_cm.png` для слайдов.
3. Записать адрес репозитория на GitHub.

### 14.2. Установка программ на ноутбуке (нужен интернет)

1. **Python 3.11** с python.org. В установщике поставить галочку «Add python.exe to PATH».
2. **Git** с git-scm.com (настройки по умолчанию).
3. Закрыть и заново открыть PowerShell, проверить: `python --version`, `git --version`.
4. **ffmpeg**: `winget install Gyan.FFmpeg`, затем снова перезапустить PowerShell, проверить `ffmpeg -version`.
   Если `winget` нет, скачать ffmpeg вручную и добавить папку `bin` в PATH.

### 14.3. Код и окружение

```powershell
cd $HOME
git clone <адрес_репозитория> emotion_project
cd emotion_project
python -m venv venv
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
venv\Scripts\activate
```

PyTorch ставится по-разному. Узнать, есть ли видеокарта NVIDIA: `nvidia-smi`.

```powershell
# есть NVIDIA:
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
# видеокарты нет (процессор):
pip install torch torchvision torchaudio

pip install opencv-python mediapipe librosa scikit-learn pandas matplotlib tqdm transformers pillow soundfile
```

Не ставьте всё из `requirements.txt` одной командой: там версия PyTorch с суффиксом `+cu118`, которая на ноутбуке
без NVIDIA не установится.

### 14.4. Веса и видео

1. Создать папку `outputs` в корне проекта и положить в неё четыре файла `.pth` (см. 14.1).
2. Проверить, что есть `models\haarcascade_frontalface_default.xml` (он в Git; если нет, команда в разделе 4).
3. Видео положить, например, в `C:\demo`.

### 14.5. Первый запуск (обязательно с интернетом, не в аудитории)

При первом запуске скачиваются две вещи и сохраняются в кэш: `facebook/wav2vec2-base` (около 360 МБ) и веса ResNet18
ImageNet (около 45 МБ). Без этого шага офлайн на показе ничего не запустится.

```powershell
python src\check_env.py
python src\predict_ensemble.py "C:\demo\video1.mp4"
python src\annotate_video.py "C:\demo\video1.mp4"
```

Предупреждения про `HF_TOKEN`, `symlinks` и `UNEXPECTED` ключи wav2vec2 безопасны.
Если команда падает, не закрывайте окно: скопируйте текст ошибки целиком.

### 14.6. Проверка без интернета

```powershell
$env:HF_HUB_OFFLINE = "1"
python src\predict_ensemble.py "C:\demo\video1.mp4"
```

Работает офлайн: хорошо. Если нет, проверьте, что шаг 14.5 был выполнен на этом же ноутбуке и под той же учётной записью.

### 14.7. Порядок показа (5-7 минут)

1. Слайды: задача, три канала (лицо, голос, жесты), схема late fusion, данные, деление по актёрам.
2. Таблицы результатов и матрицы ошибок (разделы 2 и 2.1).
3. Живой запуск: `predict_ensemble.py` на подготовленном видео, затем `annotate_video.py` (или готовый
   `*_annotated.mp4`).
4. Ограничения (раздел 9): актёрские данные, английский язык, небольшой тест, жесты не реализованы
   (если к показу так и останется).

### 14.8. Запасной план

- Перед показом открыть PowerShell, перейти в папку проекта, активировать `venv`, запустить одну команду для проверки.

- Зарядка ноутбука, питание от сети: на процессоре и на батарее обработка заметно медленнее.
